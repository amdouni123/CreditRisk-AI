
# CreditRisk AI - Intelligent Credit Scoring

## Description
Projet académique de Machine Learning pour estimer
la probabilité de défaut de crédit.

## Dataset
Statlog German Credit Data (UCI).

## Algorithmes comparés
- Logistic Regression
- Decision Tree
- Random Forest

## Métriques
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Explainable AI
- Permutation Importance
- Logistic Regression Coefficients
- Individual prediction contributions

## Technologies
Python, Pandas, NumPy, Scikit-learn,
Matplotlib, Seaborn, Streamlit.

## Lancement local
Installer les dépendances :

pip install -r requirements.txt

Lancer l'application :

streamlit run app.py

## Avertissement
Ce projet est un prototype pédagogique.
Il ne doit pas être utilisé pour des décisions
réelles d'octroi de crédit.
